# Cleanup Old Codebase Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove obsolete artifacts from the `refactor/foundation` branch, creating a clean `cleanup/old-code-removal` branch that contains only the current, production‑ready files.

**Architecture:** Straight sequence of git operations, file system deletions, and verification steps. No new software components are added; the plan manipulates existing repo state.

**Tech Stack:** Bash, Git, Python (for test execution),pción, and the repo’s current package ecosystem.

## Global Constraints
- All file names and paths must match exactly how they appear in the repository.
- Testing is performed with `pytest` under the existing virtual‑environment `~/.claude-env/venv`.
- No external network access is required.
- Branch creation must preserve the current working tree state.
- Commit messages must end with the standard `Co-Authored-By: Claude <noreply@anthropic.com>` trailer, consistent with the golden workflow.

### Task 3: Identify obsolete artifacts

**Files:**
- None (manual inspection)

**Steps:**
- [ ] Review the repo tree for any of the following that are not part of the current platform:
  - `benchmarks/`, `docs/`, or any `example/` directories.
  - `scripts/old_*` files.
  - Historical `tests/legacy_*` files.
  - Configuration files that are superseded by the new config under `config/` (e.g., `old_config.yaml`).
- [ ] Create a list file `docs/superpowers/plans/obsolete-files.txt` containing the relative paths, one per line. Example:
  ```text

  examples/
  scripts/old_utility.py
  tests/legacy_*"
  ```

**Verify:**
- Run `cat docs/superpowers/plans/obsolete-files.txt-list` to confirm entries.

### Task 4: Remove the identified files/directories

**Files:**
- Modify: `docs/superpowers/plans/obsolete-files.txt`

**Steps:**
- [ ] Read the list and delete each path: `xargs -p rm -rf`.
  ```bash
  cat docs/superpowers/plans/obsolete-files.txt | xargs -p rm -rf
  ```

**Verify:**
- `git status` should list only the deleted files.
- `ls` should no longer show the removed paths.
